Frequently Asked Questions

Common questions regarding checkout configuration, compatibility, billing, and performance.

How does CartForge integrate into my checkout? ↓

CartForge is built natively on Shopify’s Checkout Extensibility framework (purchase.checkout.block.render). You position the widget directly inside the Shopify Theme and Checkout Editor by dragging the block into your desired location (e.g. above payment or order summary).

Does this app inject tracking scripts into my theme? ↓

No. CartForge injects zero theme script tags, zero external tracking pixels, and zero bulky JavaScript bundles. All UI elements run securely within Shopify’s sandboxed web workers and are served directly from Shopify's global edge network.

How does the 1-Click Order Bump add-on work? ↓

You select a product or variant from your catalog (for instance, Priority Shipping, Warranty Protection, or an accessory). When a shopper selects the checkbox in checkout, Shopify's native Cart API immediately appends the item to the order subtotal without reloading the page.

Can I configure multiple reward tiers? ↓

Yes. You can define tiered milestone thresholds. For instance, Tier 1 at $50 unlocks Free Shipping, and Tier 2 at $100 unlocks a complimentary gift item. The dynamic progress bar animates smoothly as shoppers adjust cart contents.

What plans does CartForge support? ↓

CartForge supports all Shopify merchants with access to Checkout Extensibility (including Shopify Plus, Basic, Shopify, and Advanced stores that have upgraded to Checkout Extensibility).
