CartForge Documentation

Complete reference for configuring tier rewards, order bumps, checkout extensibility targets, and analytics.

1. Architectural Overview & Security

CartForge is built natively on Shopify's Checkout Extensibility architecture. Unlike legacy checkout apps that relied on theme code injection or custom checkout scripts (checkout.liquid), CartForge runs in an isolated, secure Web Worker sandbox provided directly by Shopify's edge infrastructure.

Checkout Block Target

In-Checkout
purchase.checkout.block.render

Renders the gamified tier progress bar and 1-click order bump directly within the one-page checkout stream.

Post-Purchase Target

Post-Payment
purchase.post-purchase.render

Presents high-converting 1-click complementary offers between payment authorization and the order confirmation page.

2. Milestone Thresholds & Dynamic Tokens

Milestone tiers calculate the customer's cart subtotal in real time and visually communicate the exact gap needed to unlock free shipping or free gifts.

Dynamic Token Substitution

Use the following token inside your message templates to display live numerical values:

{remaining} → Formatted gap amount (e.g. $14.50)
{threshold} → Target milestone tier value (e.g. $50.00)
  • Single Tier: A simple goal (e.g., "$50 for Free Shipping").
  • Multi-Tier Stacking: Progressive goals (e.g., Tier 1: $50 Free Shipping → Tier 2: $100 Free Sample Kit).
  • Reward Fulfillment: Configured to trigger Shopify automatic shipping rate discounts or automatically append promotional line items upon milestone completion.

3. 1-Click Order Bumps

Order bumps allow merchants to present high-margin accessories, shipping insurance, gift wrapping, or warranty protection directly inside the checkout form.

  • Product Variant Selection: Select any active product variant from your Shopify catalog. Stock availability is validated dynamically.
  • Shopify Policy Compliance: Checkboxes are unchecked by default to comply with Shopify App Store requirements and consumer protection standards.
  • Instant Subtotal Synchronization: Ticking the order bump modifies the checkout lines atomically with zero latency and recalculates taxes and totals in real time.

4. Post-Purchase 1-Click Upsells

The post-purchase flow takes advantage of vaulted customer payment tokens directly after initial transaction authorization:

1
Initial Checkout Complete: Buyer submits order payment. Shopify reserves the authorization token and triggers purchase.post-purchase.render.
2
One-Click Acceptance: Customer views exclusive discounted add-on and taps "Accept Offer". No card number re-entry or friction required.
3
Automated Order Mutation: The existing order is atomically updated with the add-on item before moving to the final thank-you page.

5. Shopify Markets & Multi-Currency

CartForge dynamically supports international stores running Shopify Markets:

  • Presentment Currency: Threshold amounts and order bump prices automatically format in the customer's local currency (USD, EUR, GBP, CAD, AUD, etc.).
  • Market Specific Rules: Set different milestone tier targets based on local market pricing policies.

6. Merchant Polaris Analytics

The embedded Shopify Polaris dashboard tracks real-time performance telemetry:

  • Gross Impressions: Total checkout sessions where CartForge UI extensions rendered.
  • Bump Take Rate: Percentage of buyers who accepted the 1-click order bump.
  • Milestone Conversion: Percentage of orders that successfully reached the milestone tier.
  • Incremental Revenue Lift: Net additional GMV generated exclusively by CartForge offers.

7. Troubleshooting & Common Questions

Where is the best place to position the checkout block?

In the Shopify Checkout Customizer, placing the CartForge Checkout Bar directly above the Order Summary items or immediately above the Shipping Method selector achieves the highest conversion rates.

Does CartForge work with Shop Pay and express checkouts?

Yes! Because CartForge is built on Checkout Extensibility, it is fully compatible with Shop Pay, Apple Pay, Google Pay, and PayPal Express.

How are app subscriptions billed?

All CartForge plans are billed directly through your official Shopify invoice using Shopify Recurring Application Charges. You can upgrade, downgrade, or cancel anytime in your Shopify Admin.
