CartForge Documentation

Complete reference for configuring tier rewards, order bumps, checkout extensibility targets, and analytics.

1. Architectural Overview

CartForge is built entirely on Shopify's native Checkout Extensibility architecture. Unlike legacy checkout apps that relied on theme code injection or custom checkout scripts (checkout.liquid), CartForge uses Shopify's secure Web Workers API.

2. Milestone Thresholds & Rules

Milestone tiers calculate the customer's cart subtotal in real time and visually communicate the gap needed to unlock perks.

  • Tier Threshold: The subtotal required to complete the tier (e.g. $50.00).
  • Message Template: Dynamic token replacement. Use {remaining} in your copy to automatically display the remaining dollar amount required.
  • Reward Type: Configure shipping fee waivers or free gift items with automated line item appending.

3. 1-Click Order Bumps

Order bumps allow merchants to present high-margin accessories, shipping insurance, or warranty protection directly inside the checkout form.

  • Product Variant GID: Link any existing product from your Shopify catalog.
  • Checkbox State: By default, unchecked to ensure full transparency and compliance with consumer protection guidelines.
  • Subtotal Synchronization: Selecting the checkbox triggers an immediate subtotal calculation without refreshing the page.

4. Merchant Analytics & Reporting

The Polaris dashboard tracks core performance metrics:

  • Checkout Impressions: Total checkout sessions where CartForge blocks were viewed.
  • Take Rate & Conversions: Number of completed orders that accepted the order bump or reached the reward tier.
  • Incremental Revenue Lift: Total additional revenue generated specifically from CartForge checkout add-ons.
