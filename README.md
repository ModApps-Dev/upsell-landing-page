# Checkout Upsell Engine — Official Website & Documentation

The official high-converting marketing landing page, documentation, and compliance site for the **Checkout Upsell Engine** Shopify App.

Live Domain: `https://upsell.modapps.dev`

## Features Included
- **Modern Responsive Design:** Tailored for high-growth ecommerce brands and Shopify Plus merchants.
- **Interactive Live Simulator:** Prospective merchants can drag a cart subtotal slider and toggle the order bump to see the engine react in real time.
- **Shopify App Store Compliance:**
  - `privacy.html`: Comprehensive GDPR & CCPA privacy policy required for app review.
  - `support.html`: Knowledge base, FAQs, and contact points.
- **Optimized Visuals:** High-res mockups for checkout order bump and Polaris analytics dashboard.

## DNS Setup for `upsell.modapps.dev`
In your domain DNS manager for `modapps.dev` (e.g., Cloudflare, Namecheap, GoDaddy):
Add a **CNAME** record:
- **Type:** `CNAME`
- **Name / Host:** `upsell`
- **Target / Value:** `ModApps-Dev.github.io`

In GitHub repository settings:
1. Go to **Settings** > **Pages**.
2. Source: Deploy from branch `main` / `root`.
3. Custom domain: `upsell.modapps.dev`.
4. Enforce HTTPS: Checked.
